# 202333490-lamisalhababi-assignment2

## Personal Portfolio – Assignment 2

This project is an improved version of my Assignment 1 personal portfolio website.

The website presents my background, skills, projects, and contact information. Assignment 2 adds interactive features using JavaScript to make the portfolio more useful and engaging.

## Assignment 2 Features

- Project search while typing
- Project filtering by category
- Expandable project details
- Light and dark theme toggle
- Theme preference saved using `localStorage`
- Contact-form validation
- Success and error messages
- Empty search-result feedback
- Hover effects and smooth transitions
- Responsive design for desktop, tablet, and mobile devices
- Accessible labels, buttons, and live status messages

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Flexbox
- CSS Grid
- Media queries
- SVG
- Browser `localStorage`
- Git and GitHub
